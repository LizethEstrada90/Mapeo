Flujo Operacional Principal

¿Cómo funciona Prevem Seguros?

📋 Proceso de Emisión

Los agentes realizan cotizaciones a través del portal web para seguros individuales (gastos médicos y accidentes personales). Para formalizar, envían documentos a la Mesa de Control, donde el equipo interno utiliza AXEL (sistema central) para crear la póliza en la base de datos Oracle.

🚨 Proceso de Siniestros

Cuando ocurre un siniestro, se registra en Insurance (sistema especializado). Este se comunica con ACSEL para validar coberturas y generar pagos. Puede ser por reembolso (cliente paga y recupera) o pago directo al hospital.

🔗 Integración Completa: Todos los sistemas se conectan a la misma base de datos Oracle, garantizando consistencia de información. Los pagos se procesan a través de Tesorería con transferencias bancarias automatizadas.
